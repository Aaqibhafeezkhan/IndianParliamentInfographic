What is intentionally not calculated

The explorer does not currently calculate member activity totals, attendance, debate participation, questions asked, Bills introduced, committee performance or similar rankings from these resources. Those metrics require separately validated, reproducible datasets and definitions.

Methodology

Primary sources
Lok Sabha member directory · Rajya Sabha member directory.
Retrieval
—
Browser retrieval time; not a source publication date.
Coverage
18th Lok Sabha sitting members and current sitting Rajya Sabha members returned by the official endpoints.
Source-backed fields
Name, house, party, state/UT, constituency where supplied, membership status, terms and available biographical fields.
Unavailable fields
Attendance, questions, debates, bills, assets, liabilities and criminal cases remain null unless separately validated from authoritative source records.
Derived values
Counts, shares, rankings and comparisons shown by the application are calculated from the loaded official member records and are not presented as directly sourced facts.
Historical reference layer
Historical chronology and archive links are maintained in data/history.json. The application does not treat those archives as an embedded historical member dataset; current member records remain the separate runtime source.
Archive
legacy.html is retained only as an archival copy of the previous application and is not used by the production data loader.
